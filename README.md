# Sam's Corner
I have always had an interest of cars, and have always loved the City of Newcastle. I like the vaporwave aesthetic as well. 

Sam In Newcastle is my answer to incorporating the above in a project that allows me to learn more about web development.

## What does this website actually do?
This website renders a 3d model of Sam (My ford focus) in a 3D rendering of the city of Newcastle.

The lighting will change depending on the current time, with a user override if the user wants a specific time instead.

The user will be able to choose different 3D environments to put Sam in, all based on photos taken from different parts of Newcastle.

## Website features (Planned and implemented)
### Implemented
- Live updating time
- Redirect to my GitHub
- Sam Engine start sound effect for when user enters main part of website

### Planned
- Sound ambience from recordings in Newcastle
- Accurate weather modelling based on real time weather information in Newcastle
- Vaporwave/Synthwave/Relaxed music playlist playing in background
- 3D rendering of Sam
